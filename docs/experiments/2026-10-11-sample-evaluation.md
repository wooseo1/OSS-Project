# AI Hub 샘플 전체 평가 — 2026-10-11

전체 WAV/JSON 4쌍, 합계 **111.88분**의 음성을 사용해 **20회 파일 전체 추론**을 완료했다. 샘플은 동일한 화자 표기 1개, 대본 낭독 방식이다. 기존 공개 모델 비교이며 새 학습·개인화는 수행하지 않았다.

사전에 고정한 VAD 묶음 처리에서 기본 Whisper의 통합 CER은 **15.63%**, 선행연구 통합 학습 모델은 **4.36%**였다. 차이는 **11.27%p**다. 이는 이번 샘플에서의 관측값이며 독립 테스트 성능이나 일반적인 개선폭이 아니다.

## 전체 파일 4개를 모두 평가한 결과

통합(micro) 지표: 파일별 오류 개수 합 / 전체 정답 단위 수. CER·WER 모두 낮을수록 좋다.

| 입력 처리 | 기본 CER | 선행 모델 CER | 기본 WER | 선행 모델 WER |
| --- | ---: | ---: | ---: | ---: |
| VAD 묶음 처리 | 15.63% | 4.36% | 32.62% | 10.27% |
| VAD 구간별 독립 추론 | 17.60% | 31.52% | 36.08% | 41.94% |

VAD 구간별 조건은 반복 문장의 누락을 발견한 뒤 추가한 탐색 실험이다. 해당 구간은 실제 문장 경계로 사람이 검수한 발화가 아니며, 문장 중간에서 나뉠 수 있다.

## 사전 고정 조건의 파일별 결과

| 샘플 | 기본 CER | 선행 모델 CER | 기본 WER | 선행 모델 WER |
| --- | ---: | ---: | ---: | ---: |
| sample_01 | 4.26% | 9.36% | 12.66% | 7.59% |
| sample_02 | 60.56% | 9.01% | 65.44% | 11.03% |
| sample_03 | 3.27% | 1.91% | 13.62% | 7.78% |

CER 기준 3개 파일에서 선행 모델이 개선되고 1개에서는 악화됐다. CER과 WER은 띄어쓰기·오류 단위의 차이로 방향이 다를 수 있다.

| 샘플 | 기본 CER: VAD 끔 | 기본 CER: VAD 묶음 | 선행 CER: VAD 끔 | 선행 CER: VAD 묶음 |

100%를 넘는 CER은 계산 오류가 아니다. 정답보다 삽입 오류가 많으면 발생한다. 긴 무음에서 추가된 출력이 실제로 관찰됐다.

## 확인한 점

- 모델의 도메인 학습 효과뿐 아니라 무음 처리·구간 묶음 방식이 결과를 크게 바꾼다.
- 반복 문장 파일의 기본 CER은 VAD 묶음 처리 60.56%에서 구간별 독립 추론 20.50%로 변했다. 반복을 빠뜨린 오류를 모델 성능만의 문제로 단정하지 않는다.
- 구간별 독립 추론이 모든 파일에서 좋아지는 것은 아니다. 짧게 잘린 입력의 문맥 손실도 고려해야 한다.
- 전체 정답을 이용했으므로 구간 정답을 추정하거나 모델 출력에 맞춰 정답을 선택하지 않았다.

## 재현 조건과 검증

- 모델 리비전: [연구 기반 기록](../research-base.md). 상세 실행법·지표 정의: [평가 방법](../evaluation.md).
- Python 3.12, macOS Apple Silicon, CPU int8, 4 threads, language ko, beam 5, temperature 0, 이전 텍스트 조건 끔.
- VAD threshold 0.3, min_silence_duration_ms 500, speech_pad_ms 400.
- CER: NFC·소문자화·문장부호·공백 제거 후 한글 음절 단위. WER: 같은 정규화 후 공백 기준 어절 단위.
- 문장부호를 보존한 보조 지표, 파일 평균, 대치·삭제·삽입 개수도 원 결과에 기록했다.
- 지표·합산·반복 보존·시간 오프셋 검증 7개, 별도 편집거리 재계산, 입력 길이·해시·완료 개수·덮어쓰기 방지 확인.
- 입력·모델·토크나이저·실행 코드 SHA256과 환경 버전을 로컬 기록에 보관했다.
- 원 음성·환자 메타데이터·전체 정답·추론 출력은 GitHub 커밋에 포함하지 않는다. 이 문서는 집계 수치만 포함한다.

## 한계와 다음 작업

단일 화자 표기의 4개 샘플이며 선행 모델 학습 데이터와 중복 여부가 미확인이다. 임상적 중증도, 정답의 오탈자와 실제 녹음의 대응을 사람이 모두 검수하지 않았다. 낭독 음성의 결과를 실생활 대화나 모든 구음장애 사용자에게 일반화할 수 없다. 논문의 질환 분류·라우팅·가중 CER 재현도 수행하지 않았다.

다음은 여러 화자의 원본 데이터를 확보해 화자·문장 중복을 통제한 평가 세트를 만들고, 발화별 음성·정답을 검수하는 작업이다. 그 뒤 적응용 음성과 평가용 음성을 분리해 LoRA·Adapter를 학습하고 같은 지표로 비교한다. 현재 관측값은 그 실험을 시작할 기반이다.
